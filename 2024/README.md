# Code Advent Repository!
## 2024
Started in summer 2025 during the [Fractal Tech Bootcamp](https://fractalbootcamp.com/) algorithms week 😊 Decided to complete them in TypeScript to practice my type safety 💪

To install dependencies:
```bash
bun install
```
To run:
```bash
bun run fileName
```

This project was created using `bun init` in bun v1.2.15. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
